# Reviewed publication scope

This package is an explicit selection of source, board configuration and documentation. It was not made by filtering the full working directory with filename exclusions.

Included: four owner-supplied device/board photographs and one separately labelled menu illustration explicitly reviewed for the README, and the pointer source, experimental backlight source and interface declarations, an ARM branch test, selected input mappings, technical findings, provenance notes and the Discussion draft.

Excluded: stock-ROM contents and images, Android donor binaries, game ROMs, all SD/filesystem images, device photos containing unreviewed identifiers, raw device logs, private keys and credentials, build toolchains, borrowed source trees, local helper/install scripts and temporary files.

The selected files were reviewed as text. The manifest records each file's SHA256. The checker rejects additions and modifications against that manifest; updating the manifest requires a new human review. This is a technical content check, not a legal guarantee or a cryptographically signed release.

No third-party firmware redistribution permission is implied. MIT has been selected for original project-owned code; the scoped license package remains separate from this documentation update. See NOTICE.md. Nothing has been uploaded as part of preparing this folder.
